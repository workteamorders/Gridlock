# Sound credits

The recordings in this folder are cut from sound effects released under CC0 1.0 (public domain), which needs no credit; they are listed here anyway.

| File | Cut from | Author |
|---|---|---|
| engine.wav | Starter-Kit-Racing/audio/engine.ogg | Kenney |
| impact.wav | Starter-Kit-Racing/audio/impact.ogg | Kenney |
| skid.wav | Starter-Kit-Racing/audio/skid.ogg | Landeplage (CC0), shipped in Kenney's racing kit |
| thud.wav | Starter-Kit-City-Builder/sounds/placement-c.ogg | Kenney |
| tick.wav | Starter-Kit-Match-3/sounds/tile-swap.ogg | Kenney |
| swish.wav | Starter-Kit-FPS/sounds/jump_c.ogg | Kenney |
| whoosh.wav | Starter-Kit-FPS/sounds/jump_a.ogg | Kenney |
| coin.wav | Starter-Kit-3D-Platformer/sounds/coin.ogg | Kenney |

Source: https://github.com/KenneyNL (repositories named Starter-Kit-*). Each repository states that its sound effects are CC0.
`scripts/make-sounds.py` rebuilds these files: cut, fade, peak at -3 dBFS, 16-bit mono WAV at 32 kHz.
